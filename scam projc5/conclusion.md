=========================================================================
  PROJECT SUMMARY
=========================================================================

  The "Cyber Scam & Phishing Detector" is a menu-driven C program that
  analyzes SMS messages, WhatsApp messages, emails, and text messages
  to detect possible cyber scams and phishing attempts.

  Key Achievements:
  
  ✓ 1542+ lines of modular C code
  ✓ 22 well-documented functions
  ✓ 50+ suspicious keywords with weighted risk scores
  ✓ 10 pattern detection rules (URLs, emails, phones, CAPS, etc.)
  ✓ Risk scoring system (0-100) with LOW/MEDIUM/HIGH classification
  ✓ Color-coded terminal output (Windows)
  ✓ File handling for persistent report storage (reports.txt)
  ✓ Scam statistics with visual bar chart representation
  ✓ Educational help page with cybersecurity tips
